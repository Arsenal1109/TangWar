## 商店描述（短文案）

**大唐霸业 — 武德天下**

隋失其鹿，群雄逐之。你是李渊。

- **回合争霸**：22 城 12 势力实时博弈，四季轮转（春生秋收冬藏），军议、计策、外交、姻盟环环相扣
- **名将如云**：35 位史实名将各携特技——李世民天策、李靖军神、房玄龄王佐；阵斩、俘将、劝降、招贤，天下英才皆可入麾下
- **兵不血刃**：谣言离间摇撼民心，劝降计一纸定城；破城守将有命运，城陷亦需代价
- **称帝建元**：八城可即皇帝位，武德/天授/义宁各定国策；群雄侧目，合纵随之
- **都督府**：拜两员都督分路出讨，后期不必城城亲征
- **三档难度**：休明 / 史实 / 虎狼——灾异丰稔、群雄攻性、经济补贴全面分级
- **史册系统**：功业十九项、编年史册、结局铭文，每一局都是一段可回溯的历史

## 操作说明

- 顶部五页签：**战况**（回合推进）、**军务**（募兵/军议/计策）、**外交**（岁贡/和亲/借兵/停战）、**内政**（城池/建设/特产）、**图鉴**（豪杰/功业）
- 将领任命：图鉴 → 点选武将 → 授职驻城 →（可）拜都督
- 每季时限：无硬性倒计时，回合由玩家推进；自动存档于每回合末

## 已知边界（非缺陷）

- sim 机器人会募兵但不施计策/外交/劝降，成就解锁率以此仪器度量；人类玩法上限更高
- 「再观天下」为结局后自由巡视，无额外目标
- 200 局级蒙特卡洛存在 ±2% 掷点流噪声（参数微调会重排共享 rng），单调性以 800 局为准
- typecheck 基线已清零（M10.1），检查范围扩至 ui + core + data 全量，任何新错误即失败
