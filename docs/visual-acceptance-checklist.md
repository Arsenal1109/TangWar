# 视觉验收清单（第一→第三层累计）

> **用途**：在 Cocos Creator 编辑器里对第一、二、三层做一次性的视觉复核，按页面/表面逐项对照勾选。三层改动均已提交（`6c94cca` / `d54b539` / `1c60bad`）。
>
> **方法**：沿用 `design-qa.md` 的**截图对照 + 分级**法——每页在 844 × 390 下截图，与目标视觉/相邻表面同框比对，记录每项状态。分级：
> - **P0** 遮挡/溢出/不可读/缺文字（必须修）
> - **P1** 明显走样/层级错（应修）
> - **P2** 细节粗糙（可修）
> - **P3** 风格性差异（记录不作修改）
>
> **来源标注**：`T1`=第一层（立体面板/按压/级联/数字滚动）、`T2`=第二层（字体/九宫格皮肤）、`T3`=第三层（氛围动效）。
>
> 每页底注参考对应实现记录：`docs/superpowers/plans/2026-08-31-suichu-tang-war-ui-polish-tier{1,2,3}-*.md`。
