> 版本：v2.0（实现同步稿）
> 日期：2026-08-28（v1.0 设计评审通过）；2026-08-31（v2.0 按实际实现同步）
> 类型：隋末唐初策略手游（单机 / 原生 APP）
>

## 1. 项目定位

一款以隋末唐初（617—626）为背景的单机策略手游。玩家固定扮演**李唐**（李渊 → 李世民），在群雄逐鹿的乱世中扩张版图、经营内政、运筹帷幄，最终统一天下。

- 题材：隋唐历史 + 演义化叙事
- 玩法：全面策略型（地图扩张 + 内政经营 + 战争征战 + 外交谋略）
- 视角：固定扮演李唐（历史主线 + 可改变历史的支线）
- 模式：单机为主，AI 驱动 13 方群雄互相征伐
- 平台：手机 APP（横屏，844 × 390 设计分辨率，双向自动旋转），Cocos Creator 3.x（TypeScript）构建原生 Android（iOS 预留）
- 美术：黑漆军帐界面 + 写实沙盘战图 + 东方历史人物立绘（v2.0 重构，原「竖屏水墨古风」方案弃用）

## 2. 时间与回合

- 时间跨度：617 年（大业十三年）— 626 年（武德九年），约 10 年 / 40 个季度
- **每季 = 一个回合**（春 / 夏 / 秋 / 冬）
- 单回合流程：
  1. 内政阶段：颁布一项内政施策
  2. 军事阶段：调兵、行军、攻城、驻防
  3. 外交 / 谋略阶段：结盟、离间、伏兵等（每回合限用）
  4. 结算阶段：各城产出与消耗、AI 行动、历史事件触发
  5. 推进：进入下一季；季节影响产出（秋冬粮产低，易缺粮）
- 开局：大业十三年秋，李渊据**晋阳 / 太原**仅数城，处于弱势；隋室尚在江都，群雄环伺

## 3. 核心资源

| 资源 | 来源 | 用途 |
|---|---|---|
| 黄金 | 税收 / 贸易 | 募兵、建设、外交、谋略 |
| 粮草 | 农田产出 | 供养军队；缺粮则逃兵 / 兵变 |
| 兵力 | 募兵 / 征召 | 守城与出征（分兵种） |
| 民心 | 内政 / 战争影响 | 影响税收、征兵、叛乱风险 |
| 威望（隐性） | 胜仗、称帝、声望事件 | 影响外交、劝降、威慑 |

## 4. 天下舆图

- 实用舆图（传统「计里画方」方格网风格），约 **22 座城池** + **7 处关隘** + 山河地形
- 关隘：雁门关、井陉、潼关、函谷关、虎牢关、大散关、剑阁（攻防加成、可伏兵）
- 地形：山脉（行军减速）、江河（渡河需水军或受损）
- **13 方群雄**：唐·李渊、隋·杨广、瓦岗·李密、郑·王世充、夏·窦建德、楚·萧铣、秦·薛举、凉·李轨、定杨·刘武周、燕·高开道、吴·杜伏威、梁·沈法兴、林·林士弘
- 城池属性：人口、粮产、金产、兵力、城防、守将、民心、商业等级

## 5. 五大系统

### 5.1 内政
- 每回合可施一项施策：劝课农桑（粮+）、开仓济民（民心+）、招募流民（人口+）、修城筑防（城防+）、整顿军备、调节税率
- 城池设施：农田、商市、兵营、仓廪（提升对应产出）
- 税率调节：重税得金多但民心降，轻税反之

### 5.2 军事
- 兵种 6 类（见第 6 节）
- 行军：按距离 + 地形消耗天数
- 攻城流程：围城（断粮降民心）→ 强攻（兵力 / 城防 / 将领）→ 破城；攻方有攻城惩罚，守方有城防加成
- 战役战报：演义化文案（如水墨大字「虎牢大捷」）

### 5.3 将领
- 五维属性：统军、政务、谋略、勇武、威望；忠诚度（可被离间策反）
- 任命：守将（守城）、统军（出征）、使臣（外交）
- 获取：初始名臣、战役招降、事件加入
- 李唐核心人物见第 10 节

### 5.4 外交
- 操作：结盟、停战、进贡、和亲、威胁
- 关系值 -100 ~ 100，驱动 AI 态度
- 特殊对象：突厥（可结盟借兵，亦可引兵南犯）

### 5.5 谋略
- 成功率基于将领谋略与双方差距
- 类型：离间（降敌将忠诚）、计取（劝降）、伏兵（关隘伏击）、谣言（降敌民心）、策反

## 6. 兵种（六种，最终版）

| 兵种 | 定位 | 特点 | 克制 |
|---|---|---|---|
| 府兵 | 均衡步兵 | 招募便宜、攻守均衡、基础兵种 | — |
| 精兵 | 精锐步兵 | 强攻攻坚 | 克府兵；被弩兵、玄甲军克制 |
| 骑兵 | 机动作战 | 行军最快、野战强势 | 克弩兵、府兵；被玄甲军克制 |
| 弩兵 | 远程压制 | 守城 / 攻城利器 | 克精兵、府兵、玄甲军；被骑兵克制 |
| 玄甲军 | 李唐专属精锐重骑 | 战力最高、冲锋最强、粮耗高；数量稀少、招募极贵，需达成条件（称帝 / 重大战役）解锁 | 克骑兵、精兵、府兵；被弩兵远程克制 |
| 水军 | 舟师渡江 | 渡河渡江必需，水战强势；陆战较弱 | 水战碾压；无船渡江严重损耗 |

克制闭环：骑兵 克 弩兵 → 弩兵 克 精兵 / 府兵 / 玄甲军 → 精兵 克 府兵；玄甲军 克 骑兵 / 精兵 / 府兵；水军制衡江河。

## 7. 战争结算（回合制）

- 两军相遇 / 攻城时，按 **兵力 × 将领 × 兵种克制 × 地形 / 城防 × 随机数** 结算
- 结果：胜 / 负、双方伤亡、俘虏
- 胜方可：招降 / 斩杀 / 释放俘虏（影响声望）
- 不做即时战斗，全程战报结算；v2.0 增加可跳过的全屏战斗过场演出（行军动画、四阶段推进、闪光震屏、捷报 / 军情急报结算卡），仅表现层，不改变结算规则

## 8. AI 与历史事件

- 13 方群雄各有**性格**（进取 / 守成 / 权谋 / 扩张倾向）与国力成长曲线
- AI 互相攻伐，版图动态变化
- **历史事件链**驱动主线：瓦岗李密强盛 → 王世充夺洛阳称帝 → 刘武周南下攻晋阳 → 虎牢关大捷等；玩家行为可改变历史（历史分支）
- 每回合推送「天下大事」事件消息

## 9. 胜利与结局

- 主线：617 起兵 → 618 前攻占长安 → 李渊称帝（武德）→ 逐步统一 → 626 玄武门事件（进入李世民时代 → 贞观）
- 失败：李唐势力被灭；或 618 未能入主长安（进入弱势支线）
- 结局分级：统一天下（最佳）/ 偏安 / 覆灭，附结算画面

## 11. 视觉与交互（v2.0 横屏军帐双屏）

- 设计分辨率：844 × 390，横屏双向自动旋转；全局系统 serif 字体 + 金 / 朱砂描边（兼顾 Android 兼容性）
- 色彩体系：墨黑、木色、朱砂、青灰、纸色、金色；选中态、危险区、正负资源反馈语义化
- 主战页「军帐双屏」：左侧 650px 写实沙盘战图 + 右侧 194px 军议栏 + 底部全宽作战进程 + 右下长按传令区
- 三项军议（回合决策）：防御（固守待援）/ 突袭（袭击敌军）/ 安抚（招抚降附），各有目标、预计回合、胜算与粮耗；选中后路线、时间线与收益同步，长按传令推进回合
- 页面体系（七页）：世界 / 城池 / 部队 / 计策 / 外交 / 情报 / 设置；地图工具四项（地形 / 势力 / 城池 / 标记）切换，城池卡可进「调兵 / 城内」
- 战斗过场：军令执行全屏演出——沙盘战图打底、贝塞尔行军路线动画、敌阵脉动、四阶段推进、闪光 + 震屏、捷报 / 军情急报结算卡；可「跳过演出」，开启「快速战报」后加速
- 开场引导：背景对话 + 三步操作引导（选择军议 → 看懂作战进程 → 长按传令），聚光遮罩分步高亮，设置页可重看；引导完成状态本地记忆（`tangwar:onboarding:v3`）
- 动效：太原选择环、军令路线、领土警示、行军节点、传令呼吸与按住进度
- 关键位图资产：写实沙盘战图（横版）、军议 / 时间线 / 地图工具图标、李世民与刘文静立绘（`assets/resources/redesign/`，源图归档于 `art-source/generated/`）

## 12. 技术架构（Cocos Creator 3.x / TypeScript，v2.0 现状）

- 单主场景（`assets/scenes/main.scene`）+ 运行时程序化搭建：`Bootstrap` 装配画布 / 相机 / 纸张底幕后仅挂载首屏组件；主战页 `ui/WarCouncilScreen` 以 Graphics 自绘沙盘并叠加 `redesign/` 位图资产，全局系统 serif 字体
- 模块划分（现状）：
  - `data/`：势力、城池、将领、施策、兵种、历史事件数据表（TypeScript 常量）
  - `core/`：游戏状态、回合管理、资源结算、施政 / 设施、军事（六兵种 / 募兵 / 行军 / 战斗结算）、将领、外交、谋略、群雄 AI、历史事件、胜利判定、存档序列化（全部引擎无关、可单测）
  - `ui/`：`WarCouncilScreen` 军帐主战屏（沙盘战图、军议、作战进程、七页面、战斗过场、开场引导、设置）、`SoundManager` 音频、`SaveManager` 存档桥接；`TopBar` / `BottomNav` / `CitySheet` / 五功能面板为 v1 竖屏遗产，v2.0 起不再装配（代码暂留待清理）
  - `map/`：v1 舆图渲染与相机，v2.0 起由军帐主战屏内置沙盘取代（保留未装配）
- 音频：`assets/resources/audio/bgm-council.ogg` 军帐 BGM（循环、音量 0.32，首次触摸手势解锁后播放）+ 命名音效 `resources/sounds/*`（缺失时优雅降级为日志）；设置页「军帐音乐」开关经 `audio-setting` 事件联动
- 存档：本地 JSON（`sys.localStorage`，键 `tangwar_save_v1`，版本守卫）；回合推进自动存档 + 设置页手动存档（`save-requested`）
- 测试：`tests/` 纯逻辑层（node + vitest），17 个文件 72 用例
- 目标平台：Android 原生 APP（Cocos 导出，根目录 `build-apk.ps1`），iOS 预留
