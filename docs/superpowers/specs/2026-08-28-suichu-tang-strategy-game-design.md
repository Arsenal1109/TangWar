# 《隋唐风云》游戏设计文档

> 版本：v1.0（设计评审通过稿）
> 日期：2026-08-28
> 类型：隋末唐初策略手游（单机 / 原生 APP）

## 1. 项目定位

一款以隋末唐初（617—626）为背景的单机策略手游。玩家固定扮演**李唐**（李渊 → 李世民），在群雄逐鹿的乱世中扩张版图、经营内政、运筹帷幄，最终统一天下。

- 题材：隋唐历史 + 演义化叙事
- 玩法：全面策略型（地图扩张 + 内政经营 + 战争征战 + 外交谋略）
- 视角：固定扮演李唐（历史主线 + 可改变历史的支线）
- 模式：单机为主，AI 驱动 13 方群雄互相征伐
- 平台：手机 APP（竖屏），Cocos Creator 3.x（TypeScript）构建原生 Android（iOS 预留）
- 美术：水墨古风界面 + 实用舆图 + 东方写实古风人物立绘

## 2. 时间与回合

- 时间跨度：617 年（大业十三年）— 626 年（武德九年），约 10 年 / 40 个季度
- **每季 = 一个回合**（春 / 夏 / 秋 / 冬）
- 单回合流程：
  1. 内政阶段：颁布一项内政施策
  2. 军事阶段：调兵、行军、攻城、驻防
  3. 外交 / 谋略阶段：结盟、离间、伏兵等（每回合限用）
  4. 结算阶段：各城产出与消耗、AI 行动、历史事件触发
  5. 推进：进入下一季；季节影响产出（秋冬粮产低，易缺粮）
- 开局：大业十三年秋，李渊据**晋阳 / 太原**仅数城，处于弱势；隋室尚在江都，群雄环伺

## 3. 核心资源

| 资源 | 来源 | 用途 |
|---|---|---|
| 黄金 | 税收 / 贸易 | 募兵、建设、外交、谋略 |
| 粮草 | 农田产出 | 供养军队；缺粮则逃兵 / 兵变 |
| 兵力 | 募兵 / 征召 | 守城与出征（分兵种） |
| 民心 | 内政 / 战争影响 | 影响税收、征兵、叛乱风险 |
| 威望（隐性） | 胜仗、称帝、声望事件 | 影响外交、劝降、威慑 |

## 4. 天下舆图

- 实用舆图（传统「计里画方」方格网风格），约 **22 座城池** + **7 处关隘** + 山河地形
- 关隘：雁门关、井陉、潼关、函谷关、虎牢关、大散关、剑阁（攻防加成、可伏兵）
- 地形：山脉（行军减速）、江河（渡河需水军或受损）
- **13 方群雄**：唐·李渊、隋·杨广、瓦岗·李密、郑·王世充、夏·窦建德、楚·萧铣、秦·薛举、凉·李轨、定杨·刘武周、燕·高开道、吴·杜伏威、梁·沈法兴、林·林士弘
- 城池属性：人口、粮产、金产、兵力、城防、守将、民心、商业等级

## 5. 五大系统

### 5.1 内政
- 每回合可施一项施策：劝课农桑（粮+）、开仓济民（民心+）、招募流民（人口+）、修城筑防（城防+）、整顿军备、调节税率
- 城池设施：农田、商市、兵营、仓廪（提升对应产出）
- 税率调节：重税得金多但民心降，轻税反之

### 5.2 军事
- 兵种 6 类（见第 6 节）
- 行军：按距离 + 地形消耗天数
- 攻城流程：围城（断粮降民心）→ 强攻（兵力 / 城防 / 将领）→ 破城；攻方有攻城惩罚，守方有城防加成
- 战役战报：演义化文案（如水墨大字「虎牢大捷」）

### 5.3 将领
- 五维属性：统军、政务、谋略、勇武、威望；忠诚度（可被离间策反）
- 任命：守将（守城）、统军（出征）、使臣（外交）
- 获取：初始名臣、战役招降、事件加入
- 李唐核心人物见第 10 节

### 5.4 外交
- 操作：结盟、停战、进贡、和亲、威胁
- 关系值 -100 ~ 100，驱动 AI 态度
- 特殊对象：突厥（可结盟借兵，亦可引兵南犯）

### 5.5 谋略
- 成功率基于将领谋略与双方差距
- 类型：离间（降敌将忠诚）、计取（劝降）、伏兵（关隘伏击）、谣言（降敌民心）、策反

## 6. 兵种（六种，最终版）

| 兵种 | 定位 | 特点 | 克制 |
|---|---|---|---|
| 府兵 | 均衡步兵 | 招募便宜、攻守均衡、基础兵种 | — |
| 精兵 | 精锐步兵 | 强攻攻坚 | 克府兵；被弩兵、玄甲军克制 |
| 骑兵 | 机动作战 | 行军最快、野战强势 | 克弩兵、府兵；被玄甲军克制 |
| 弩兵 | 远程压制 | 守城 / 攻城利器 | 克精兵、府兵、玄甲军；被骑兵克制 |
| 玄甲军 | 李唐专属精锐重骑 | 战力最高、冲锋最强、粮耗高；数量稀少、招募极贵，需达成条件（称帝 / 重大战役）解锁 | 克骑兵、精兵、府兵；被弩兵远程克制 |
| 水军 | 舟师渡江 | 渡河渡江必需，水战强势；陆战较弱 | 水战碾压；无船渡江严重损耗 |

克制闭环：骑兵 克 弩兵 → 弩兵 克 精兵 / 府兵 / 玄甲军 → 精兵 克 府兵；玄甲军 克 骑兵 / 精兵 / 府兵；水军制衡江河。

## 7. 战争结算（回合制）

- 两军相遇 / 攻城时，按 **兵力 × 将领 × 兵种克制 × 地形 / 城防 × 随机数** 结算
- 结果：胜 / 负、双方伤亡、俘虏
- 胜方可：招降 / 斩杀 / 释放俘虏（影响声望）
- 不做即时战斗，全程战报结算

## 8. AI 与历史事件

- 13 方群雄各有**性格**（进取 / 守成 / 权谋 / 扩张倾向）与国力成长曲线
- AI 互相攻伐，版图动态变化
- **历史事件链**驱动主线：瓦岗李密强盛 → 王世充夺洛阳称帝 → 刘武周南下攻晋阳 → 虎牢关大捷等；玩家行为可改变历史（历史分支）
- 每回合推送「天下大事」事件消息

## 9. 胜利与结局

- 主线：617 起兵 → 618 前攻占长安 → 李渊称帝（武德）→ 逐步统一 → 626 玄武门事件（进入李世民时代 → 贞观）
- 失败：李唐势力被灭；或 618 未能入主长安（进入弱势支线）
- 结局分级：统一天下（最佳）/ 偏安 / 覆灭，附结算画面

## 11. 视觉与交互

- 界面：水墨古风（宣纸底、墨色横幅、朱砂回纹、卷轴选项卡、印章按钮）
- 地图：实用舆图（计里画方网格、势力领土色块、江河湖海、山脉关隘、驿道、罗盘比例尺）
- 竖屏手机布局：顶部紧凑状态栏 → 全屏舆图 → 底部导航（政/兵/将/盟/谋 + 中央「回合」按钮）→ 城池底部卡片 → 功能底部弹层
- 关键动效：回合推进季节动画、城池弹层滑出、战报水墨大字

## 12. 技术架构（Cocos Creator 3.x / TypeScript）

- 单主场景 + 运行时程序化搭建：地图用 Graphics 绘制（不依赖美术资源），UI 用预制体 + 系统字体，先跑通玩法、后期替换美术
- 模块划分：
  - `data/`：势力、城池、将领、施策、事件数据表（TypeScript 常量，可迁移 JSON）
  - `core/`：游戏状态、回合管理器、资源系统、事件总线、存档
  - `map/`：舆图渲染（Graphics）+ 地图交互（点击 / 拖动 / 缩放）
  - `ui/`：顶部栏、底部导航、城池卡片、功能弹层、弹窗
  - `ai/`：群雄 AI 决策（扩张 / 外交 / 防守）
  - `battle/`：战争结算
- 存档：本地 JSON（自动 + 手动槽位）
- 目标平台：Android 原生 APP（Cocos 导出），iOS 预留
