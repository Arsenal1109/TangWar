> **状态：✅ 代码与资产已落地**（类型检查与单测通过；编辑器内视觉复核清单见文末）。
>
> 承接第一层（立体面板/按压/级联/数字滚动）与第二层（字体/九宫格皮肤）。第三层为氛围层：传令烛光呼吸、地图云影漂移、军议卡选中扫光、Toast 分级。全部为**零交互逻辑回归**的纯视觉增强，特效贴图程序化生成（`tools/gen-effects.mjs`），资源未导入时自动降级为无特效运行。

**Goal:** 在既有精致骨架上加入"会呼吸"的动态氛围，让主战页与人机反馈更具临场感。

**Tech Stack:** 同前（Cocos Creator 3.8 + TS；`tools/` 用 node + zlib 生成 PNG；vitest 纯逻辑单测）。

## 资产：三张氛围特效贴图（`tools/gen-effects.mjs`）

| 贴图 | 尺寸 | 用途 |
|---|---|---|
| `glow-warm` | 128×128 | 传令印信后的烛光暖晕（径向暖橙，边缘平滑衰减） |
| `cloud-soft` | 256×128 | 地图云影（fbm 软云团，外围淡出成独立云） |
| `sweep-gold` | 96×128 | 军议卡选中扫光条（左右软渐变的垂直金带） |

零外部依赖（`node:zlib` 编码 PNG + 固定随机种子），经 PNG 回读 CRC 与像素逐字节校验，合计约 39KB。每张带 Cocos `.meta`（image/texture 格式同第二层）。

## 代码改动（`assets/scripts/ui/WarCouncilScreen.ts`，+93/-11）

**① 传令印信烛光呼吸**
- `buildOrderGlow()`：在 HoldOrder 之外生成暖晕 Sprite（150×150，置于按钮之下），`startGlowFlicker()` 以多段不规则透明度 + 微缩放做 "烛光呼吸"（repeatForever）。
- 长按（`onHoldStart`）时停掉呼吸、把暖晕增亮到 225 并放大约 1.16，模拟"印信受热发亮"；松开/结算（`onHoldEnd`/`resetOrderButton` → `restoreOrderGlow`）回弹到呼吸态。

**② 地图云影漂移**
- `buildCloudLayer()` → 两团 `cloud-soft` 以不同位置、速度、透明度（42/30）缓速往复 + 透明度起伏，营造沙盘上空云影流转。

**③ 军议卡选中扫光**
- `refreshReport` 选中卡调用 `sweepHighlight(card, 178, 48)`：一条 `sweep-gold` 金带自左向右扫过卡片一次后销毁（左右软渐变，边缘过界处已透明，无需裁剪）。

**④ Toast 分级**
- `showToast(text, tone)`：`tone: 'normal' | 'good' | 'bad'`。文字与左侧小色条按语义着色——成功绿 / 警告失败红 / 常规纸色金点。
- 各关键反馈接入 tone：施政/募兵/任将/计策/进贡成败、传令结算（按战报 tone）、粮草不足、黄金不足、手动存档等。
